TinyTracer — colour-fx stage, live replay

Demo scene, 256×256, 8 spp. Pixel order and timing come from the chip model (sim/tinytracer_sim.cpp, per-pixel cycle counts at 25 MHz) plus the UART: one pixel is rendered while the previous one is sent, and the RTU stalls when the UART falls behind. The fx stage is applied to each pixel at the moment it leaves the Accumulator, using the same integer logic as the proposed RTL. Changing controls mid-render behaves like the pins (takes effect on the next pixel).
